# Vakao - 视频速度控制器

一个轻量的 Manifest V3 扩展：给任意网站上的 HTML5 `<video>` 统一加上倍速控制和快捷键，不依赖构建步骤，也不需要任何第三方依赖。

## 功能

- **快捷键控制**：`Z` 减速 0.1x，`X` 重置 1.0x，`C` 加速 0.1x（按住可连续变化）。
- **数字键直接设速**：连按数字组成目标倍速（如 `1` `5` 得到 15x），800ms 无输入或按 `Enter` 立即生效，`0` 表示取消。
  数字键可以在面板里关掉，关掉后改为 `Alt + 数字`，把 `0-9` 还给站点（如 YouTube 的跳转进度）。
- **按站点记忆倍速**：调过的倍速记在 `chrome.storage.local`，刷新页面、切换站点、SPA 换集、播放器重建后会自动套用。
- **面板预设**：0.25x ~ 16x 共 16 个档位，自动高亮当前档位。
- **iframe 内播放器**：内容脚本注入所有 frame；按键发生在没有视频的 frame 时，会把动作转发给父子 frame。
- **不抢站点的键**：只在真的要接管时拦截事件；站点已 `preventDefault` 的按键、带 `Cmd/Ctrl` 的组合、输入法组合态、输入框内的按键一律让位。
- **浮层提示**：左上角显示当前倍速，用 shadow DOM 承载（站点样式穿不进来）、`position: fixed` 定位，全屏播放也可见。

## 安装

本扩展未上架商店，用开发者模式加载：

1. 打开 `chrome://extensions/`，右上角开启「开发者模式」。
2. 点「加载已解压的扩展程序」，选择本目录（含 `manifest.json` 的那层）。
3. 建议把图标固定到工具栏。

改动代码后，在扩展管理页点该扩展的刷新按钮即可生效；已经打开的标签页不需要手动刷新——打开面板时会自动补注入内容脚本。

## 使用

### 快捷键

| 按键 | 作用 |
| --- | --- |
| `Z` | 减速 0.1x（下限 0.1x） |
| `C` | 加速 0.1x（上限 16x） |
| `X` | 重置为 1.0x |
| `0`-`9` | 输入倍速，`Enter` 立即确认，`0` 取消 |
| `Alt` + `0`-`9` | 仅当面板里关闭「数字键直接设速」时生效 |

调整倍速时左上角会出现当前倍速提示。

### 面板

- 顶部显示当前视频的实时倍速；没有视频时显示「未检测到视频」，浏览器内部页面（`chrome://`、应用商店等）显示「此页面不可用」并置灰。
- 点击预设档位直接应用，当前生效档位高亮。
- 底部「数字键直接设速」开关即时生效，已打开的页面不需要刷新。

## 实现要点

```
video-speed-control/
├── manifest.json          # MV3 配置：内容脚本注入所有 frame，权限 storage / scripting
├── popup/                 # 面板：结构、样式、交互三项放一起，整体可搬动
│   ├── popup.html
│   ├── popup.css
│   └── popup.js
├── content/
│   └── content.js         # 页面侧：选视频、快捷键、浮层、记忆、iframe 转发、面板通信
└── icons/                 # 图标
```

- **视频发现**：每次操作时重新查询，不缓存元素引用，因此不依赖 SPA 的路由事件；顶层找不到时会穿透 shadow DOM 再找一次，结果做 500ms 缓存避免连发时反复遍历。
- **选哪个视频**：全屏中的 > 正在播放的 > 可见面积最大的，页面上常驻的广告 / 预览小窗不会顶掉主播放器。
- **记忆与套用**：按 `vsc:rate:<hostname>` 存倍速，只在 `loadedmetadata`（新视频 / 重新加载）时套用，不和站点自带的倍速选择器互相打架；站点自己改的倍速不会被强行改回。
- **面板通信**：统一走 `chrome.tabs.sendMessage`（带 `__vsc` 标记），消息会广播到标签页内所有 frame，只有真正持有视频的 frame 才应答 `get` / `set`。

## 已知限制

- 只支持标准 HTML5 `<video>`；Canvas / MSE 自绘播放器不支持。
- 部分站点会在设置后立刻重置 `playbackRate`，这类站点无法覆盖。
- `<video>` 元素自身进入全屏时无法叠加浮层（浏览器不渲染其子节点），此时调倍速不显示提示，但倍速仍然生效。
- `chrome://`、Chrome 应用商店等页面禁止注入内容脚本。
